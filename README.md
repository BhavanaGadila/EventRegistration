# Event Registration

A simple web-based Event Registration application developed using HTML. The application allows users to enter their registration details and view the submitted information on a separate page.

## Features

- Event registration form
- Displays submitted registration details
- Simple and user-friendly interface
- Clean HTML structure

## Technologies Used

- HTML

│── index.html
